# eTax Manager

Quản lý hóa đơn điện tử: đồng bộ từ cổng Thuế, tra cứu, báo cáo VAT, xuất Excel/PDF/XML. HTML5 + CSS3 + JavaScript ES2024 thuần, chạy Web / PWA / Electron.

```bash
node server/server.mjs   # rồi mở http://127.0.0.1:8080
```

Xem [docs/HUONG-DAN.md](docs/HUONG-DAN.md) để biết cách cài đặt, sử dụng và xử lý sự cố.
